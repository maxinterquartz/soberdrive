Политика конфиденциальности и обработки персональных данных

1. Общие положения

1.1. Настоящая Политика определяет порядок обработки персональных данных пользователей на сайтах talk.soberdrive.ru и balls1.ru (далее — Форум).

1.2. Оператором данных является Максим Владимирович Нырко.

1.3. Используя Форум или регистрируясь на нем, пользователь выражает полное согласие с условиями настоящей Политики.

2. Состав собираемых данных

2.1. Оператор собирает следующие данные:

  • Данные при регистрации: адрес электронной почты (e-mail), никнейм (псевдоним).
  • Технические данные: IP-адрес, файлы cookies, данные о браузере и уникальный идентификатор пользователя (ID).
  • Информация в профиле: любые данные, которые пользователь добровольно указывает о себе.

3. Цели обработки

3.1. Обеспечение функционирования площадки для общения, модерация сообщений и предотвращение спама.

3.2. Идентификация пользователя для защиты учетной записи.

4. Публичность данных

4.1. Размещая сообщения, Пользователь самостоятельно делает свой никнейм и текст сообщений общедоступными.

4.2. Оператор не несет ответственности за раскрытие Пользователем личной информации в публичных разделах Форума.

5. Порядок удаления и обезличивания

5.1. Пользователь может потребовать удаления учетной записи через запрос на e-mail: forum@soberdrive.ru.

5.2. При удалении аккаунта созданные пользователем сообщения и темы сохраняются для поддержания логики дискуссий.

5.3. При удалении происходит полное обезличивание: связь сообщений с e-mail и IP разрывается, а никнейм автора заменяется на системный статус (например, «Удаленный пользователь»).
